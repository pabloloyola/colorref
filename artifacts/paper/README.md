# Paper evidence and illustration artifacts

These files support provenance and reproduction; they are not Overleaf inputs.
The active manuscript and import instructions are in [`../../paper/`](../../paper/).

- `figure-data/calibration_effects.json`: reported rounded estimates used for
  the calibration figure, not a fresh raw-response recomputation.
- `figure-data/southern_lime_green.json`: the selected saved trajectory.
- `evidence/trajectory-gallery-20261009/`: author's compact 16-case export and
  transport manifest. Displayed colors, errors and 48 oracle messages were
  verified; full prompts, checkpoint files and full-run completion were absent.
- [Gallery PDF](galleries/trajectory-gallery-20261009.pdf)
- [Gallery ZIP](galleries/trajectory-gallery-20261009.zip): individual PDF/PNG
  figures, compact data, manifest, combined PDF and HTML index.

These are unchanged moves from the pre-cleanup paper folder. Original checkpoint
hashes are retained as supplied; the compact transport cannot independently
verify the original files. Selected examples illustrate behavior and do not
estimate aggregate performance. Rebuild commands are in the paper README.
