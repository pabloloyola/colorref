\section{Corpus Construction and Examples}
\label{sec:appendix-dataset}
\label{app:corpus-examples}

The ColorNames-derived source pairs user-provided color names with sRGB HEX
codes. Preprocessing retains English strings with valid HEX codes and a
description-validity score greater than 0.75. The original validity scoring
uses GPT-4o to judge whether a string plausibly functions as a color description,
accepting literal, figurative, and subjective expressions while rejecting
spam, URLs, nonsensical strings, and personal messages. This score is not
a measure of inter-speaker agreement about the paired color. Canonicalization
assigns stable identifiers and normalizes fields; color conversion produces
RGB, HSV, and CIELAB coordinates. The final corpus has 518{,}830 rows.

\paragraph{Structural parser.}
The deterministic parser lowercases strings, maps punctuation to spaces,
removes nonalphabetic characters, and collapses whitespace. It scans tokens
right-to-left for a basic-color head; preceding tokens are partitioned into
known modifiers and unknown prefix content. Confidence decreases with
unexplained prefixes. Parser v2 additionally normalizes selected \emph{-ish}
forms and plurals, allows prototype heads when no basic head is found, and
records prototype hits throughout the name. Hand-curated YAML lexicons and
explicitness, prototype, rarity, and abstraction scores determine the regime.

\section{Oracle Wording and Receiving Prompts}
\label{app:bandwidth_wording_examples}

The subscript $c1$, $c2$, or $c3$ specifies a maximum constraint count,
not a magnitude. For target \texttt{\#A0B0C0} and guess \texttt{\#805000},
the implementation selects muted, lighter, and blue in that order. These
examples are generated by the available code with example ID 0, seed 13,
and feedback turn 0; they are not recovered historical experiment messages.

\begin{center}
\small
\begin{tabular}{@{}lp{0.65\columnwidth}@{}}
\toprule
Condition & Example feedback \\
\midrule
Minimal $c1$ & Make it more muted. \\
Axis $c1$ & Make it more muted. \\
Axis $c2$ & Make it more muted and lighter. \\
Axis $c3$ & Make it more muted, lighter, and more blue. \\
Template $c1$ & Make it less saturated. \\
Template $c2$ & Make it less saturated. Move toward a brighter shade. \\
Template $c3$ & Make it less saturated. Move toward a brighter shade.
Move it toward blue. \\
\bottomrule

Template conditions use deterministic alternative phrases for the same
selected directions; the phrase bank does not add \emph{a little} or
\emph{much}. These modifiers belong to the separate magnitude studies.
Minimal and axis-$c1$ are equivalent in this controlled setting.
The template-vocab implementation still selects primitive LAB/HSV directions;
broader warmer/cooler or gray dictionary entries do not establish a matched
broad-vocabulary ceiling. No-candidate fallback messages can differ.

The common HEX revision template is:
\begin{quote}\small\ttfamily\raggedright
\detokenize{You are playing a color guessing game.}\par\medskip
\detokenize{Color description:}\par
\detokenize{"{raw_name}"}\par\medskip
\detokenize{Your previous guess was: {previous_guess_hex}}\par
\detokenize{Feedback: {feedback}}\par\medskip
\detokenize{Revise your guess.}\par
\detokenize{Answer only with a valid hex code in the form #RRGGBB.}\par
\end{quote}
The initial HEX template omits the previous guess and feedback and asks
for the intended color. New receiving studies use unchanged teacher text
in the feedback field. The guesser does not receive the target or oracle
constraint JSON as additional prompt fields. All contexts are fresh.

Plain LAB revisions instead request \texttt{LAB(L, a, b)} within
$L\in[0,100]$ and $a,b\in[-128,127]$. The legend explicitly states that
increasing/decreasing $L$ makes the color lighter/darker, increasing/decreasing
$a$ shifts toward red/green, and increasing/decreasing $b$ shifts toward
yellow/blue. Previous displayed LAB coordinates have six decimal places.
These rectangular bounds are encoding bounds, not the sRGB gamut boundary.
The model must supply three numeric values; unevaluated expressions and
incomplete triples are not repaired.

\section{Matched Controls and Reproducibility}
\label{app:new-controls}

\subsection{Shared-start interface control}
The 64 descriptions are balanced across regimes. Starts come from the
completed parent HEX predictions, not new predictions by each receiving
interface. Target LAB is recomputed from recorded target HEX. The same
oracle thresholds and ranking operate on displayed uint8 sRGB states in
every arm. First corrections are identical; later corrections respond to
the arm's own displayed state. Three revisions are forced even after a
close guess, which differs from the original early-stopping protocol.
All 576 generated revisions parse, so first/final matched cohorts contain
all 64 examples. First alignment denominators are 64/61/63 for HEX/plain
LAB/legend LAB because some updates have zero length.

Final native errors are 22.781, 35.589, and 23.325; displayed errors are
22.781, 35.275, and 23.161. Mean projection errors over generated states
are 0, 0.783, and 0.937. Thus, an axis legend does not uniformly reduce
projection cost. These results must not be mixed with the earlier
own-initial-prediction interface study, whose common cohort is 61/64 after
three legend-condition parse failures.

\subsection{Isolated wording probes}
For each of 12 fixed colors and six requested directions, compare bare,
\emph{a little}, \emph{somewhat}, and \emph{much} under plain and legend
prompts. Each response is independent; the ordinal comparison does not
chain the resulting states. Exact 5-/10-unit controls explicitly name a
coordinate and hold the other two fixed. Twelve no-change cases per prompt
complete the 888-response plan. All responses parse. The qualitative ladder
has three pairwise comparisons per starting-color/direction combination,
216 comparisons per prompt. Bare wording has no ordinal rank.

\subsection{Calibration policy and target construction}
Calibration and one-step evaluation use 12 colors each drawn from an inclusive
sRGB channel range [48,208], with seed 29. A subsequent seed-47 transfer split
contains twelve fresh starts, excluding the earlier calibration/evaluation
starts, isolated anchors, and the inspected close-case start by exact HEX.
Inputs and feasibility decisions are frozen before inference.

Calibration generates 12 colors $\times$ six directions $\times$ four
wordings, or 288 responses (287 parsed). For each direction and phrase,
take the median displayed signed step among parsed responses, retaining
zero/wrong-sign updates. Bare wording is not a selection candidate;
graded phrases with positive medians are. Select the median closest to the
current axis residual, breaking ties by smaller median and then ladder order.
No held-out response refits this mapping.

Native target candidates move one coordinate by 6, 12, or 24 units.
Retain candidates within the prompt bounds whose projection error is at
most one and whose displayed residual follows the intended direction.
This produces 196/216 one-step targets and 200/216 transfer targets;
excluded inputs are not replaced. Generated outputs remain unfiltered.
Displayed target construction and six-decimal prompted coordinates are
stored separately from exact instructed targets.

All arms use the same supplied start and target. Bare feedback specifies
direction. Calibrated feedback supplies a selected magnitude phrase.
Numeric feedback specifies an exact increment and holds the other coordinates;
it is a precision/execution control, not information-matched wording.
Sequential transfer retains the original axis throughout, stops at the
first displayed error at most five, and caps generation at five revisions.
If the axis residual is at most 0.01 while total error exceeds five,
the protocol permits an explicit off-axis-residual ending instead of an
empty correction. No such ending occurs in the completed transfer study.
Reaching the cap is a valid observed endpoint, not an imputed success.

\subsection{Uncertainty and saved inputs}
Paired bootstrap draws resample whole starting colors for magnitude studies
and whole examples within regimes for interface/teacher studies, keeping
associated direction/distance or bandwidth cases together. All use 2{,}000
resamples and seed 13. Pooled case weights remain unchanged; twelve starts
are twelve clusters, not hundreds of independent colors. Available-pair
sensitivity equals common-triplet estimates in the completed magnitude
studies because every evaluation response parses.

Frozen configuration, plans, calibration/controller snapshots, rendered
prompts, responses, parsing results, native/displayed states and scores are
retained. Resume validates hashes, scores and observed model revision; backend
failures stay pending, while invalid generated outputs remain failures.
The observed model snapshot is recorded in run metadata. CPU inspectors
write supplementary reports without changing checkpoints or fitting policies.
Software tests use simulated outputs and do not supply model-performance evidence.

\section{Magnitude and Stopping Diagnostics}
\label{app:magnitude_diagnostics}

\subsection{One-step limitations}
Calibrated versus bare has 93 wins, 57 ties and 46 losses on 196 targets
at an exploratory 0.01 $\Delta E$ tie tolerance. Mean differences for
6-/12-/24-unit targets are $-9.84$, $-5.77$, and $+0.85$, respectively;
the 24-unit interval spans zero. The red calibration ladder has a large gap
between \emph{somewhat} (5.073) and \emph{much} (75.844) displayed units.
This diagnoses coarse resolution, not an identified internal linguistic
mechanism. Per-start leave-one-out mean effects remain favorable, but are
descriptive leverage checks rather than new intervals or grounds for exclusion.

The exact numeric control has 188/196 native responses within 0.01 of the
instructed coordinates and 192 within one. Four larger misses are 39, 32,
12, and 10 units. They terminate at EOS below the output budget and preserve
unrequested coordinates, with projection displacement below 0.5. They remain
in reported performance. For example, an instructed red-axis change from
$-43.698223$ to $-37.939764$ instead returns $1.060236$, a 39-unit miss.
Observed execution/transcription failure does not prove a particular internal
digit or sign-loss mechanism.

\section{Teacher Prompts, Audits, and Reception}
\label{app:teacher_controls}

The natural zero-shot condition preserves the archived oracle-assisted
prompt: it supplies correct directions as JSON and asks for a natural short
comparative paraphrase. Its vocabulary includes LAB/HSV primitives as well
as warmer/cooler and gray terms. The restricted prompt instead requests
exactly the supplied primitive directions, prohibits additions, omissions,
reversals, substitutions and magnitude modifiers, and requires a single
\emph{Make it} sentence. This changes multiple instructions and the allowed
format simultaneously; it does not isolate one individual wording instruction.

Four-shot prompts use canonical oracle answers for four input-selected
demonstrations. IDs are 202953, 207855, 39272, and 352171; evaluation excludes
these IDs and normalized description or target/guess-pair overlap. The same
IDs and order appear in both forms, with bandwidth-specific answers.
The final 60 examples contain 15 per regime; each is evaluated at $c1$ and
$c3$. The clause budget equals the maximum supplied direction count and
never forces lossy compression. Demonstrations do not cover every direction:
darker and more saturated are absent from their logged primitive coverage.

All teacher conditions use Qwen3-14B, temperature zero, thinking disabled,
and an 80-token output cap; the HEX receiver uses the same model family
and a 64-token cap. Four-shot prompts necessarily cost more input tokens.
The five receiving arms use every message unchanged, with no target-HEX
mentions observed and no parse failures in 600 revisions. There is no new
teacher generation for the deterministic oracle arm.

\subsection{Frozen lexical audit versus scope-aware diagnostics}
Primary conservative certification requires an exact detected direction set,
without unknown or ambiguous wording or duplicate mentions. It is an
operational format/vocabulary criterion, not semantic ground truth.
Supplementary finite-grammar auditing resolves explicit guess-versus-target
comparisons and a leading \emph{Feedback:} label while retaining unresolved
language for review. It does not overwrite primary scores.

For example, the response \emph{Your guess is darker than the target color}

22 unresolved cases is retained separately; it is neither independent human
annotation nor a replacement for the finite-grammar or primary metrics.
No review label selects teacher messages for receiving evaluation.

Restricted zero-shot versus oracle partitions into 98 identical messages
(all ties), six different messages preserving the lexical direction set
(sum error difference $-126.040$; 3 wins, 1 tie, 2 losses), and sixteen
messages with additions (sum $-94.853$; 8 wins, 5 ties, 3 losses).
Together these yield the observed mean $-1.841$, but median zero.
The 57.1\%/42.9\% contributions describe net arithmetic effects, not a
randomized test of ordering, wording, or added information. The six same-set
messages must be inspected before identifying a particular surface mechanism.

Eight addition cases use only threshold-qualified extra primitive directions;
eight do not. Threshold qualification is neither sufficient for useful
magnitude nor necessary for a direction to have a correct sign. Some
contradictory primitive messages still improve target error, underscoring the
distinction between fidelity and usefulness. Natural-language keyword
additions are scope-sensitive and are not semantic bandwidth violations.
Across all arms, identical actual prompts never yield different parsed
colors in the saved audit; this is observed consistency, not a proof of
backend determinism. Restricted four-shot ties the oracle on 118/120 cases.
